A Python program that writes a one-sentence pitch for Sigh-Fi, the worst app ever: it detects your sighs and emails a monthly sigh report to your manager, because wellness is measurable.

Competition: [The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23)

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, single line, 133 characters) to `/output/entry.txt`.
